# Car Sharing Project (UI Practice)

A frontend-focused car-sharing interface built with Vue.js and SCSS, created to practice responsive design, UI interactions, and layout patterns.

## Features

- Responsive layout (mobile + desktop)
- Interactive UI components
- Vehicle selection interface (UI only)
- Booking form mockup

> ⚠️ Note: Backend API is currently no longer operational. UI interactions work for demonstration only.

## Technologies

- Vue.js
- JavaScript
- SCSS / CSS

## Local Setup

```bash
git clone https://github.com/JuliettKhar/car-sharing-project-example.git
cd car-sharing-project-example
npm install
npm run serve
```

You can view the live version [here](https://juliettkhar.github.io/car-sharing-project/).
